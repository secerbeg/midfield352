# 3-5-2 Midfielder Guide

This package contains the midfielder-specific website core.

Upload the files to the root of your GitHub Pages repository and place the 13 MP4 clips in `assets/videos/` using the filenames referenced by `script.js`.

The page focuses on Inter midfielders #20, #22 and #23 and uses only the Inter vs AC Milan match clips selected in this project.

Full-match source: https://www.youtube.com/watch?v=otyyT6vAq0Y
